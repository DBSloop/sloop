Asking for something

sloop is built from a list its owner keeps, informed by people who run these databases every day. If something you need is missing, the repository is where to say so — and a description of the problem is worth more than a description of the feature, because the refusals on this page exist where the obvious feature was the wrong answer to a real problem.
